# 模式库速查（方向 / 痛点 / 方案）

供 `opc-m1/opc-m2 系列 skill` 在拆解与补缺口时快速取用。**不是**填空模板，需结合具体领域改写。

---

## 1. 细分领域拆解五视角（至少交叉用两种）

### 1.1 生命周期视角

`认知期 → 入门期 → 成长期 → 成熟期 → 退出/更替期`

适用：宠物、健身、乐器、摄影、母婴、考研、装修、理财、游戏。

### 1.2 消费链路视角

`了解 → 比较决策 → 购买 → 使用 → 维护 → 分享/复购`

适用：任何有实物或付费服务的领域。痛点常密集在「比较决策」与「使用维护」。

### 1.3 场景时空视角

`宿舍 / 教室 / 通勤 / 租房 / 出差旅行 / 节假日 / 深夜 / 周末`

适用：生活服务、饮食、睡眠、社交、出行。大学生最熟悉宿舍与校园场景，优先。

### 1.4 情绪价值视角

`焦虑缓解 / 孤独陪伴 / 身份表达 / 成就感 / 掌控感 / 松弛感 / 归属感`

适用：内容、社群、打卡、兴趣类。情绪母题往往能长出 0 开发的 A/B/H 类机会。

### 1.5 支出结构视角

`刚需 / 改善 / 冲动 / 省钱 / 避损`

适用：判断付费意愿。**避损**（怕买错、怕浪费、怕踩坑）往往比「更爽」更好变现。

### 1.6 组合建议

| 领域气质 | 推荐视角组合 |
|----------|--------------|
| 有实物消费 | 消费链路 × 支出结构 |
| 技能养成 | 生命周期 × 情绪价值 |
| 生活服务 | 场景时空 × 支出结构 |
| 兴趣社群 | 情绪价值 × 生命周期 |
| 信息密集 | 消费链路 × 场景时空 |

## 2. 痛点母题库（定稿需 ≥5 种）

| 母题 | 用户口吻 | 常见量化方式 | 天然适配方案 |
|------|----------|--------------|--------------|
| **信息不对称** | 不知道该信谁 | 跨 N 个平台、耗时 X 分钟 | G 聚合 / A 内容 / E 可视化 |
| **决策困难** | 选项太多不敢下单 | 反复比较 N 次、退货率 | E 对比看板 / F 清单 |
| **坚持不下去** | 三天热度 | 2 周内中断比例 | C 打卡 / B 社群陪跑 |
| **无人陪伴/无人可问** | 半夜出问题没人答 | 问题发生频次 | B 社群 / H 轻咨询 |
| **流程繁琐** | 太麻烦懒得做 | 步骤数、每次耗时 | D 工具整合 / C 轻工具 |
| **技能不足** | 想做但不会 | 首次失败率 | A 教程 / F 模板 |
| **浪费与损耗** | 买了没用完/买错了 | 单次损失金额 | C 记录 / E 复盘看板 |
| **社交表达** | 想晒但不会呈现 | 发布放弃率 | F 模板 / A 内容 |
| **记不住/漏掉** | 忘了做 | 遗漏次数 | C 提醒工具 |
| **过程不可见** | 不知道自己进步没 | 无数据可看 | E 个人看板 |

## 3. 方案白名单速查（A–H）

| 码 | 类型 | 最小版本长什么样 | 首用户获取 | 上限风险 |
|----|------|------------------|------------|----------|
| A | 内容服务 | 5 条短视频或 3 篇干货 | 平台自然流 + 群 | 需持续产出 |
| B | 社群运营 | 一个 30 人主题群 + 每日一问 | 校内熟人裂变 | 运营耗人 |
| C | 轻量工具 | 单页小程序：录一件事+看历史 | 群里定向邀请 | 留存需内容配 |
| D | 工具整合 | 表单 + AI + 文档串成一条流程 | 手动帮前 10 人跑 | 依赖第三方 |
| E | 简单可视化 | 一张对比表/一个静态看板 | 内容引流 | 数据来源要合规 |
| F | 模板素材 | 一个模板包 + 使用说明 | 内容或社群分发 | 易被复制 |
| G | 信息聚合 | 人工整理的结构化清单页 | 搜索/口碑 | 更新成本 |
| H | 轻服务交付 | 1 对 1 帮 3 个人做一次 | 熟人 + 群 | 不可规模化（但适合课堂闭环） |

**课堂建议**：第 1–2 周先用 A/B/F/H 拿到真实用户与反馈，再决定是否投入 C/G。

## 4. 组合模式（用于生成差异化机会）

| 模式 | 公式 | 例子形态 |
|------|------|----------|
| 内容 + 工具 | A → C | 先做攻略号，再给读者一个记录小工具 |
| 社群 + 陪跑 | B + H | 21 天共学群 + 每周 1 次 1 对 1 |
| 清单 + 看板 | F + E | 采购避坑清单 + 价格对比页 |
| 整合 + 服务 | D + H | 用 AI 流程替人代整理，先人工交付 |
| 本地化 | 任意 + 地域限定 | 只服务某校/某城/某方言区 |
| 人群极窄化 | 任意 + 人群限定 | 只服务「租房限养宠」的人 |
| 反向筛选 | E/G | 不推荐买什么，而是帮人排除 |

## 6. 资质与伦理红线速查

| 领域 | 不许做 | 可以做 |
|------|--------|--------|
| 医疗健康 | 诊断、用药建议、疗效承诺 | 科普、就诊流程陪跑、康复记录 |
| 心理 | 治疗、危机干预结论 | 情绪记录、自助练习、求助资源指引 |
| 金融 | 投顾、荐股、借贷、代持资金 | 个人记账、消费复盘、避坑科普 |
| 法律 | 出具法律意见 | 流程科普、材料清单 |
| 教育 | 保过承诺 | 方法、练习设计、陪学 |
| 食品 | 功效宣称 | 食谱、采买、记录 |
| 个人数据 | 采集他人隐私、爬私域 | 用户自愿录入自己的数据 |

危机线索类内容（自伤等）必须给出求助资源指引，不做替代性专业判断。

# M4 · 秒哒生成提示词（固定模板块）

> 本文件是 M4 Step 7 输出「秒哒生成提示词」的唯一模板与填充规范。
> 规则：整段纯文本（无表格 / 无 markdown 符号），顺序固定，品质宣言放最后、逐字使用。

## 一、品质宣言（固定文案，逐字使用）

```text
【品质宣言】
设计标准（双锚点）：可用性对标一线互联网产品（Keep/小红书/大众点评）的移动端界面品质，
达到"专业设计团队打磨"的水准；视觉体验对标 Awwwards 顶级数字作品的完成度，绝不呈现套模板的粗糙感。
视觉语言：统一使用同一套线性图标（Lucide 风格），全程禁止用 emoji 当图标、禁止裸露占位图；
色彩有主次、层级分明，圆角与间距风格全站统一。
创意自由度：在功能清晰可用的前提下，把每一屏当作精雕细琢的产品界面：讲究排版节奏、留白、
微动效与即时反馈，让每个页面超出普通"表单工具"的观感。
体验标准：{移动端优先（375px）/ 桌面端优先}，信息密度合理，交互反馈即时，让用户第一眼判断"这是正经上线产品"。
```

> 仅允许把「移动端优先（375px）」按产品形态替换为「桌面端优先」；其余文字不改。

## 二、模板骨架（顺序固定）

```text
【产品是什么】
产品名称：{产品名}
一句话定位：{为谁解决什么问题}
形态：{小程序 / H5 / 网站 / App}（{移动端优先 / 桌面端优先}）

【目标用户】
{目标用户画像：谁、在什么场景、有什么顾虑}

【页面与功能】（{N} 页）
1. {页面名}
   内容：{页面上有什么}
   操作：{用户能做什么，点了去哪}
2. {页面名}
   内容：…
   操作：…
…（逐页展开，来自需求文档字段 0 产品形态 / 3 功能列表 / 4 业务流程）

【核心交互要求】
每功能完整闭环：操作 → 系统反馈 → 结果保存 → 可再次查看；
表单有校验（必填提示）、空态有引导文案、加载有状态；按钮点击有反馈。

【数据】
预置 {X} 条示例数据：{具体预置内容}；
字段：{页面/功能}={字段1/字段2}（来自需求文档字段 5）

【交付要求】
{N} 页完整可演示；{主流程}全流程可点通；
{移动端 375px 适配 / 桌面端适配}；空态/加载态/错误态齐全；直接可用无需补页。

【边界】
不做 {登录注册 / 支付 / 后台管理 / 其他明确不做项}。

【品质宣言】
（逐字粘贴上面的固定文案，放整段提示词最后）
```

## 三、填充规则

| 模板段 | 从需求文档哪来 | 要求 |
|--------|----------------|------|
| 产品是什么 | 字段 1 项目背景 + 字段 0 产品形态 | 一句话定位 + 形态必写 |
| 目标用户 | 字段 2 目标用户 | 承接 M2 的「用户+场景」 |
| 页面与功能 | 字段 3 功能列表 + 字段 4 业务流程 | 逐页「内容+操作+去向」；核心功能必须完整闭环，不许只写静态页 |
| 核心交互要求 | 字段 7 非功能性 + 通用规则 | 固定段落，一般不改 |
| 数据 | 字段 5 数据字段定义 | 必须给"预置几条、什么内容"，防空壳 |
| 交付要求 | 字段 8 验收标准 | 页面数 / 主流程 / 适配写死 |
| 边界 | Step 2 第 10 题"不做清单" | 直接抄，防平台加戏 |
| 品质宣言 | —（固定） | 放最后，逐字使用，只许改移动/桌面 |

## 四、完整成品示例（猫粮助手）

```text
【产品是什么】
产品名称：猫粮助手。一句话定位：帮多猫家庭 3 分钟选对粮。
形态：微信小程序（移动端优先，375px）。

【目标用户】
多猫家庭主人、新手养猫者，预算敏感，怕买错粮、怕配料看不懂。

【页面与功能】（4 页）
1. 首页
   内容：顶部问候区 + 今日推荐 3 款猫粮（横向卡片：匹配度/价格/蛋白质）+ 快捷入口（选粮/猫况档案/对比）
   操作：点推荐卡 → 进对比页；点快捷入口 → 对应页面
2. 选粮页
   内容：问卷式引导（猫龄/体重/健康问题/预算）逐题作答 → 结果页推荐列表（卡片排序 + 匹配度 + 数据来源小字）
   操作：答案改变 → 推荐实时刷新；点某款 → 详情/对比
3. 猫况档案
   内容：猫咪档案列表（名字/头像/猫龄/体重/健康问题）
   操作：新增/编辑/删除；保存后首页推荐按档案个性化
4. 对比页
   内容：2-3 款猫粮横向对比（价格/成分/蛋白质/适用猫况/数据来源）
   操作：对比项可增删；从首页/选粮结果一键带入

【核心交互要求】
每功能完整闭环：操作 → 系统反馈 → 结果保存 → 可再次查看；
表单有校验（必填提示）、空态有引导文案、加载有状态；按钮点击有反馈。

【数据】
预置 3 份猫咪档案示例（不同猫龄/体重/健康问题）；
预置 5 款真实猫粮数据（名称/价格/成分/蛋白质/适用猫况/数据来源）；
字段：档案=名字/猫龄/体重/健康问题；猫粮=名称/价格/蛋白质/成分/来源。

【交付要求】
4 页完整可演示；首页→选粮→对比全流程点通；
375px 适配；空态/加载态/错误态齐全；直接可用无需补页。

【边界】
不做登录注册、不做支付/商城、不做后台管理。

【品质宣言】
设计标准（双锚点）：可用性对标一线互联网产品（Keep/小红书/大众点评）的移动端界面品质，
达到"专业设计团队打磨"的水准；视觉体验对标 Awwwards 顶级数字作品的完成度，绝不呈现套模板的粗糙感。
视觉语言：统一使用同一套线性图标（Lucide 风格），全程禁止用 emoji 当图标、禁止裸露占位图；
色彩有主次、层级分明，圆角与间距风格全站统一。
创意自由度：在功能清晰可用的前提下，把每一屏当作精雕细琢的产品界面：讲究排版节奏、留白、
微动效与即时反馈，让每个页面超出普通"表单工具"的观感。
体验标准：移动端优先（375px），信息密度合理，交互反馈即时，让用户第一眼判断"这是正经上线产品"。
```

- 品质宣言**只出现在秒哒生成提示词段**（M4 输出）；**M6 迭代指令不携带**品质宣言（保持纯功能修改指令）。

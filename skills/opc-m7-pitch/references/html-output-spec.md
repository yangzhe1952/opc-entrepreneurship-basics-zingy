# HTML 成果物输出规范（V3 · 主题色个性化 + Awwwards 级设计标准）

> 适用：OPC 8 个 Skill 的最终成果物导出。定稿后，AI 必须把成果物渲染成一份**自包含 HTML 文件**（内联 CSS，单文件可打开），**对标 Awwwards / FWA / CSS Design Awards 顶级网站设计品质**，供学生直接保存提交。
>
> **V3 核心变化**（对比 V2）：
> ① **不再有固定配色**——每个 HTML 必须按「本模块产品/行业语义 + 人选的风格」派生**独特主题色**，禁止所有成果物共用同一套黑底金色；
> ② 交付前必须对照 **§6 自检清单**逐项核对；
> ③ **乱码防控**——`<meta charset="UTF-8">` 置于 `<head>` 第一行、禁止 emoji 与特殊图形符号、交付时提示保存为 UTF-8。

---

## 0. 必守铁律（违反即返工）

1. **先读本规范**：生成 HTML 前，AI 必须先完整阅读 `references/html-output-spec.md`，严格按其模板与 §4 区块清单生成；越界排版、随意自创一律返工。
2. **不使用固定配色**：每个 HTML 必须有自己的主题色（按 §2 派生），**禁止**照抄共享示例里的 `#0a0c10` 黑底 `#e8b34b` 金。
3. **单文件自包含**：所有样式写在 `<style>` 内，不引用外部 CSS 文件；图标统一用 **Lucide**。
4. **全程禁止 emoji 与图形符号**：不出现 🐱📊✅（emoj 系列）、也不出现 ★●➜▶① 等图形/序号符号；一律用 Lucide 图标或纯文字表达。
5. **底部落款（必须）**：页面最底部固定一行小字，居中小字号：

   ```html
   <div class="footer">子谦国际 OPC 创业基础</div>
   ```

6. **成果物对齐**：HTML 呈现的就是该模块最终要提交的成果物（M1 赛道画像 / M2 HMW问题卡 / M3 产品任务书 / M4 需求文档 / M5 测试报告 / M6 迭代说明 / M7 路演大纲 / M8 项目档案）。

## 1. 技术硬性要求

1. **编码**：`<meta charset="UTF-8">` 必须位于 `<head>` 内**第一行**（在 `<title>` 之前）；HTML 全文只用 UTF-8 文本。
2. **Lucide 引入**：`<script src="https://unpkg.com/lucide@latest"></script>` + `<i data-lucide="...">`，JS 端 `lucide.createIcons()`。
3. **无外链资源依赖**：仅允许 unpkg Lucide 外链；不引用任何外部 CSS/字体/图片，截图除外（如有需转 base64）。
4. **保存提示**：交付时提醒人「另存为 UTF-8 编码（记事本→文件→另存为→编码选 UTF-8；推荐用 VS Code）」；若打开乱码，就是保存编码问题，重新以 UTF-8 保存即可。

## 2. 主题色派生机制（V3 核心，禁止固定色板）

每个成果物**必须有一套自己的主题色**。派生三步：

### 第一步：语义定调（行业/产品 → 情绪 → 主色）

按「这个产品是什么、解决什么、给谁用」判断情绪基调，选主色方向。参考映射（仅示例，可组合）：

| 产品/行业语义 | 情绪基调 | 推荐主色方向 |
|--------------|---------|-------------|
| 宠物陪伴、母婴 | 温暖、柔软 | 暖橙、奶油米 |
| 健康、食品、生鲜 | 新鲜、安心 | 清新绿、燕麦色 |
| 学习、工具、效率 | 理性、清爽 | 冷静蓝、纸白 |
| 文创、情感、手作 | 治愈、人文 | 陶土红、米黄 |
| 科技、效率、AI | 未来、锐利 | 电光紫、深空蓝 |
| 环保、户外 | 自然、野生 | 苔绿、大地棕 |

**通用规则**：暖色（橙红、金黄）= 温暖/食欲/活力；绿色系 = 健康/自然；蓝紫系 = 理性/科技；黑白灰作底 + 一个强调色是保底方案，但**强调色不能用共享示例的同一金色**。

### 第二步：询问人（生成 HTML 前，随反思问答一并问）

在「反思问答」之后、生成 HTML 之前，**一次性问一句**：

> 成果物我按「{推导出的风格}」来做，比如主色调是{色名}。你想要这个风格，还是想换个感觉？（也可以直接告诉我你想要的颜色/风格）

人答 → 按其偏好定色板；人不指定 → AI 按第一步推导结果定色板。

### 第三步：定 4 色色板，注入 CSS 变量

统一用 CSS 变量承载主题色，方便整体替换。色板构成：背景、卡片、主文字、次要文字、强调色、辅助色、分隔线。**背景不强制深色**，可按主题做浅色/彩色背景，但要保证「沉浸统一、文字可读、整页一致」。

泛示例（暖橙·宠物主题，仅演示结构，不得整体照抄）：

```css
:root{
  --bg:#15110e; --card:#211a15; --ink:#f7f1e8; --dim:#a89a8c;
  --accent:#e8824a; --accent-2:#d9b46a; --line:rgba(247,241,232,.12);
}
```

> 若人要求的风格与推导不同，以人选的为准；但**两次交付成品不得使用同一套色板**。

## 3. 通用 HTML 骨架（每个 Skill 按成果物填充）

```html
<!DOCTYPE html>
<html lang="zh">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>{成果物名}｜{产品/赛道名}</title>
<script src="https://unpkg.com/lucide@latest"></script>
<style>
  :root{/* 主题色变量（按 §2 派生填充），示例：--bg:#15110e;--card:#211a15;--ink:#f7f1e8;--accent:#e8824a;… */}
  /* ...Awwwards 级样式（网格背景/噪点/超大文字/滚动动效）... */
</style>
</head>
<body>
<div class="grid-bg"></div>
<div class="grain"></div>
<nav>…</nav>
<div class="wrap">
  <section class="hero">…</section>
  <section class="section">…成果物内容…</section>
  <footer><div class="brand">{品牌} 子谦国际 OPC 创业基础</div></footer>
</div>
<script>lucide.createIcons(); /* IntersectionObserver 滚动入场 */</script>
</body>
</html>
```

**设计品质底线（无论何种主题色都必须达到）**：

| 维度 | 标准 |
|------|------|
| **创意自由度** | 把浏览器视作交互式艺术画布，跳出传统卡片布局，先锋视觉、实验性排版、冲击力文字版式 |
| **文字版式** | 超大字号标题（clamp 响应式，最大 100px+），可加描边空心字（`-webkit-text-stroke`）、透明字、渐变字 |
| **布局实验** | 网格缝卡片墙、交错网格、放射光晕、大引用块（Georgia 引号）、编号章节（01/02/03） |
| **动效** | 滚动入场渐显（IntersectionObserver + `.reveal`）、按钮悬浮上浮+光晕、物理感缓动（cubic-bezier） |
| **交互细节** | 按钮/卡片 hover 变换、表格行悬停高亮、证据级别标签（E1/E2/E3）、局部吸顶导航 |
| **沉浸统一** | 全屏 hero + 网格背景渐隐蒙版；整页风格统一，无割裂 |
| **响应式** | 移动端单列、导航收敛、字号 clamp 自适应 |

| Skill | 区块（section 顺序） |
|-------|-----------------|

| M2 真实问题定义 | Hero｜20 条痛点摘要（交错网格/编号）｜深挖版｜选定条目与理由｜HMW问题卡（四字段高亮卡，**人自己手写定稿**）｜**反思（3 问）**｜数据附录 |
| M3 方案生成 | Hero｜候选方案（表）｜四维评分与选定（数据卡）｜**三轮共创记录（每轮：人的点子 + AI 受启发想法）**｜产品任务书（表）｜创新点｜**反思（3 问）** |
| M4 需求梳理 | Hero｜产品形态（醒目标签）｜八大字段（编号分区：背景/用户/功能/流程/字段/视觉/非功能/验收标准）｜MIAODA 粘贴版｜**反思（3 问）** |
| M5 AI 模拟测试 | Hero｜测试任务｜模拟画像遍历（+/？/−/！）｜**四象限便利贴画布**｜需求挖掘（L1-L4）｜问题分类统计表｜总结（无迭代建议）｜**反思（3 问）** |
| M6 迭代执行 | Hero｜待决策清单｜修改方案｜发现→修改对照表｜**秒哒可复制指令**（编号文字）｜回归验收清单｜**反思（3 问）** |
| M7 路演生成 | Hero｜8 页路演大纲（首页+六段卡片+结束页，含迭代计划）｜演讲稿底稿｜演示动线（注：M7 另用 dashi-ppt 生成正式 PPT，此 HTML 为大纲版） |
| M8 资产整理 | Hero｜**1.基本信息（含产品截图，压缩）**｜2.时间线｜3.成果物清单（内容直现 + 点击查看）｜4.关键决策记录｜5.**各模块反思**（M1–M7）｜6.方法论（人提交）｜7.个人成长（4F 反思，人提交）｜**M1–M7 二级页面（iframe 内嵌，单文件提交）**——**总大小 ≤5MB**，尽量详细呈现人做选择与决策的关键内容（理由、Yes and 点子） |

## 5. 触发与交付

- **触发**：模块定稿且人答完反思问答后**自动生成**（不再询问）；或用户说「导出 HTML」「做成文件」时执行。
- **风格询问**：生成前按 §2 第二步问一句风格/主色调偏好（并入反思问答之后同一次交互）。
- **交付**：输出**完整可运行的 HTML 代码**（不是示意图），并提示：保存为 `{成果物名}.html`，**编码务必选 UTF-8**，用浏览器打开。
- **底部落款**：任何情况下不得遗漏「子谦国际 OPC 创业基础」。

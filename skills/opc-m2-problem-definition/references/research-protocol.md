# 联网检索规程（详版）

`opc-m1/opc-m2 系列 skill` v2 的强制依赖。目标：让机会里的每个数字都**有出处、可追溯、不编造**。

---

## 1. 总原则

1. **先检索后分析**：第一步分析动笔前完成首轮检索。
2. **就高不就低**：同一事实有多级来源时用高级别。
3. **保守优先**：多源冲突取保守值，写区间。
4. **诚实降级**：查不到就标 E2/E3，绝不虚构。
5. **口径优先于数字**：一个说清口径的模糊量级，比一个来源不明的精确小数有用。

---

## 2. 四类必查数据与查询词库

### D1 市场规模与增速（第一步用）

| 查询词模板 | 说明 |
|------------|------|
| `{领域} 市场规模 2025` | 主查 |
| `{领域} 行业报告 白皮书` | 找权威机构 |
| `{领域} 用户规模 渗透率` | 人数侧 |
| `{细分领域} 市场 增速` | 逐方向补 |
| `{领域} industry market size China` | 英文源交叉 |

**要拿到**：规模数值 + 年份 + 统计口径（是零售额？用户数？交易额？）

### D2 人群规模与结构（第二步用）

| 查询词模板 |
|------------|
| `{人群} 数量 统计 2024` |
| `{领域} 消费者调研 报告` |
| `{人群} 消费特征 画像` |
| `{地域} {人群} 人数` |
| `CNNIC 互联网报告 {人群}` |

**要拿到**：人群量级 + 口径边界（城镇/全国/某年龄段）

### D3 行为与痛点（第三步用，最关键）

| 查询词模板 | 拿什么 |
|------------|--------|
| `{领域} 用户 痛点 调研` | 痛点清单 |
| `{行为} 频次 调查` | 频次 |
| `{领域} 满意度 投诉` | 不满结构 |
| `{产品类} 差评 常见问题` | 一手抱怨（S5） |
| `{领域} 用户流失 中断 原因` | 坚持不下去类 |
| `小红书/豆瓣/知乎 {领域} 求助` | 真实语料（S5，量级判断用） |

**要拿到**：可测口径（频次/耗时/占比/金额/中断率）之一

### D4 竞品与空白（第三、五步用）

| 查询词模板 |
|------------|
| `{细分需求} 小程序` / `App` |
| `{细分需求} 工具 推荐` |
| `{领域} 创业项目 案例 大学生` |
| `{痛点} 解决方案 现有产品` |

**要拿到**：已有玩家清单 + 覆盖了哪部分 → 用于差异化评分与「伪机会」剔除

## 3. 来源分级与评估

### 3.1 分级

| 级 | 类型 | 举例 |
|----|------|------|
| S1 | 政府/统计/协会 | 国家统计局、民政部、行业协会年报 |
| S2 | 权威研究咨询 | 艾瑞、易观、QuestMobile、CNNIC、麦肯锡、Statista、Frost |
| S3 | 上市公司披露 | 年报、招股书、投资者交流 |
| S4 | 主流财经媒体引述 S1–S3 | 财新、第一财经、界面 |
| S5 | 平台公开信号 | 电商榜单、应用商店评论量、社区讨论量 |
| ✗ | 无署名自媒体、SEO 站、内容农场、AI 生成站 | 不可作唯一来源 |

### 3.2 快速评估五问

1. 有**机构署名**吗？
2. 有**年份**吗？
3. 说清**口径**了吗（谁、什么范围、怎么算）？
4. 是**原始发布**还是转述的转述？
5. 数字是否**自相矛盾**或与常识量级冲突？

任一项不过 → 降级或弃用。

### 3.3 二手转述处理

只看到媒体转述 → 记为 S4，尝试搜原报告名；找不到原报告则**降为 E2**，写「据媒体引述的{机构}数据」。

---

## 4. 冲突与缺失处理

| 情况 | 处理 |
|------|------|
| 两源差 <20% | 取较低值，写「约」 |
| 两源差 >20% | 写区间「X–Y」并说明口径差异 |
| 只有旧数据（>3 年） | 可用但标年份，加「近年应有变化」 |
| 完全查不到 | 降 E3 + 验证动作；**不许**换个说法硬写成 E1 |
| 领域太新无报告 | 用 S5 一手信号做量级判断（E2），说明方法 |
| 涉资质敏感（医疗/金融/法律） | 只取规模与行为数据，不取专业结论 |

---

## 5. 检索强度对照

| research_depth | 最少检索 | 独立来源 | 场景 |
|----------------|----------|----------|------|
| quick | 3 次（D1/D2/D3 各 1） | 2 | 课堂演示 |
| **standard** | **6–8 次**（D1×2 D2×2 D3×2 D4×1） | **4** | 默认 |
| deep | 12+ 次，D4 逐方向 | 6+ | 实验班开题、写进材料 |

**回补规则**：第三步若发现新细分领域或关键数字缺失，允许并鼓励回补检索，不必等到最后。

## 6. 检索记录模板（内部用，喂给附录）

```
[R1] D1 | query: "宠物 市场规模 2025 报告"
     source: {机构/报告名} | year: 2025 | level: S2
     fact: 宠物消费市场规模约 X 亿元（口径：城镇犬猫消费）
     用于: 第一步方向1
[R2] D3 | query: "新手养猫 常见问题 调研"
     source: {平台评论聚合} | level: S5
     fact: 首月高频问题集中于饮食/排泄/应激三类
     用于: 第三步痛点，标 E2
...
```

定稿时把 R 记录整理成 SKILL §9.3 的数据来源附录表。

---

## 7. 禁令清单

- ✗ 编造报告名、机构名、URL、年份
- ✗ 把搜索结果标题的数字当已核实（未进内容 → 最高 E2 并注明）
- ✗ 用 AI 生成内容站作唯一来源
- ✗ 把 E3 假设包装成 E1 表述
- ✗ 引用宏观 AI/教育数据时违反 `knowledge/09-禁区与口径`
- ✗ 转述医疗诊断、用药、投资建议类结论

---

## 8. 未联网时的合规输出

工具不可用/全部失败时，输出顶部必须写：

> ⚠️ 本次未能联网检索，以下市场与用户数据为**课堂级估计**，所有量化痛点均标记为待验证假设，学生须自行核实后使用。

并且：

- 全部数据标 E3
- 数据附录改为「待验证假设清单 + 验证动作」
- 仍需完成五步分析与组合校验（方法价值不依赖数据可得性）
